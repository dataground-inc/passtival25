# TOP5 조회 시각 표시

## 목표

TOP5 랭킹 API 응답을 정상적으로 받은 시각을 `HH시 mm분 기준` 형식으로 노출한다. 시와 분은 각각 두 자리로 표시한다.

## 동작

- 필터별 TOP5 요청이 성공하고 응답 데이터가 배열일 때, 브라우저의 현재 로컬 시간을 조회 시각으로 저장한다.
- 조회 시각은 필터 영역 오른쪽에 `00시 00분 기준` 형식으로 표시한다.
- 로딩 중 또는 요청 실패 시에는 조회 시각을 표시하지 않는다.

## 구현 경계

- 시간 포맷은 `String.prototype.padStart(2, '0')`로 구성한다.
- `update` 요소에 직접 CSS를 적용해 실제 DOM 구조와 무관하게 글꼴과 색상이 적용되도록 한다.
- 테스트는 성공한 TOP5 응답 뒤 두 자리 조회 시각이 보이는지를 검증한다.

## 오류 처리

TOP5 요청이나 JSON 처리 실패 시 랭킹 데이터는 빈 배열로 초기화하고, 이전 조회 시각은 제거한다.
